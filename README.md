# gerador de senhas

# aviso importante!!!

# como compilar e testar
caso esteja no windows digite:

```.\makefile.ps1```

caso esteja no linux/macOS digite:

```.\makefile.sh```

caso não queira usar este comando pode usar estes abaixo
```
cargo install wasm-pack
npm install -g serve
cd docs
serve -l 8080
```
